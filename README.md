# Affinity OpenAPI

**This repository does not publish a specification or a package.** The current public API contract is served at [api.affinityrx.com/v1/openapi.json](https://api.affinityrx.com/v1/openapi.json). Its current `Affinity-Version` is `2026-10-09`.

Generate clients from that live document. The maintained official SDK is [TypeScript](https://github.com/affinity-health/affinity-typescript). Affinity has not released official Python, Go, or Java SDKs; their GitHub repositories are placeholders.

The [API documentation](https://docs.affinityrx.com/) describes authentication, Test and Live mode, and supported operations. Embedded component sessions are not part of the released public API contract.
